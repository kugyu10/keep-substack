## Phase-Specific UI Changes

### TEAM-01: private チームタブ表示

**Change scope:** `src/app/page.tsx` — 1 line only.

**Before:**
```
.filter((t) => t.status === 'public')
```

**After:**
```
.filter((t) => t.status !== 'hidden')
```

**Visual outcome:** private チームが public チームと同一スタイルのタブとして表示される。鍵アイコン・異なる色・バッジなし（D-02: same appearance as public tabs）。

**Tab appearance (unchanged):**
- Inactive: `bg-white text-[#363737] border-[#ebebeb] hover:bg-[#fafafa] hover:border-[#d8d8d8]`
- Active: `bg-primary text-white border-primary` (`#FF6719`)
- Size: `px-3 py-1 rounded text-sm border`

### ANLT-01/02: Google Analytics 導入

**Change scope:** `src/app/layout.tsx` — component addition only. No visible UI change to end users.

**Implementation pattern (D-07):**
```tsx
import { GoogleAnalytics } from '@next/third-parties/google'
// ...
{process.env.NEXT_PUBLIC_GA_MEASUREMENT_ID && (
  <GoogleAnalytics gaId={process.env.NEXT_PUBLIC_GA_MEASUREMENT_ID} />
)}
```

**Placement:** Inside `<body>`, after `<Footer />` (end of body, before closing tag).

**Visibility contract:**
- Production (Vercel, env var set): GA script injected → all pageviews tracked
- Local dev (`.env.local` has no `NEXT_PUBLIC_GA_MEASUREMENT_ID`): no script → no tracking
- Auth layout (`src/app/(auth)/layout.tsx`): no change — root layout already covers all routes including /login and /signin-* via Next.js route group inheritance

**No new UI elements** are introduced by GA. The `<GoogleAnalytics>` component renders a `<script>` tag only; it has no visual output.
