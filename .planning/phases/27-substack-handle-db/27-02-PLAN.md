## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Server Action (updateMyProfileAction) | User-submitted substack_handle is untrusted; normalized server-side |
| URL query param → auth/callback → redirect URL | ?handle= value is forwarded into redirect path; must be encoded and scoped to internal path only |
| CalendarGrid href | substackHandle from DB is injected into anchor href; must be constrained to substack.com domain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03 | Tampering | updateMyProfileAction | mitigate | `.eq('user_id', user.id)` scopes update to own row — existing IDOR mitigation continues per ASVS V4 |
