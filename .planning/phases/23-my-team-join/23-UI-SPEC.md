## Component Inventory

**Focal point:** 「保存する」ボタン（orange-500 accent、フォーム最下部に固定）が主要な視覚的アンカー。ユーザーの視線はチェックボックスリストを操作した後、自然にページ下部のオレンジボタンへ誘導される。

### 変更するコンポーネント

#### `MyProfileForm.tsx` — チェックボックスリストに置き換え

**所属チームセクションの置き換え仕様:**

```
[現行] <input type="text" name="teamNames" ... />
[新規] チェックボックスリスト
```

**publicチームのチェックボックスアイテム（参加可能）:**
```

  <input type="checkbox" name="teams" value="{teamName}"
    checked={参加中}
    class="w-4 h-4 accent-orange-500" />
  <span class="text-sm text-[#363737]">{チーム名}</span>

```

  <span class="text-sm text-[#363737]">{チーム名}</span>
  <span class="text-xs text-gray-500 ml-auto">管理者が設定</span>

## Interaction Contract

### 保存フロー

1. ユーザーがチェックボックスを操作する → チェック状態がローカルに反映される（即時保存しない）
2. 「保存する」ボタンを押す → `isPending = true` → ボタンが `disabled + opacity-50` になる
3. Server Action 完了 → 成功時: ページリロード（`revalidatePath('/my')`）、失敗時: エラーメッセージ表示
4. ボタンラベル: 通常「保存する」/ pending中「保存中...」

### Disabled 状態の視覚規則

| 状態 | 視覚表現 |
|------|---------|
| isPending (ボタン) | `opacity-50 cursor-not-allowed` |
| privateチームチェックボックス | `opacity-60 cursor-not-allowed`、チェック済み固定 |
| パブリケーションID フィールド | `bg-gray-100 text-gray-400`、readonly |

## Accessibility Contract

- チェックボックスは `<label>` で包み、ラベルクリックでチェック切り替えできること
- disabled チェックボックスには `aria-label` にチーム名 + 「管理者設定済み」を含めること
- エラーメッセージは `role="alert"` または `aria-live="polite"` で読み上げられること
- フォーム送信ボタンは disabled 時も `aria-disabled="true"` を持つこと
- タッチターゲット最小 44px 確保（`min-h-[44px]`）
