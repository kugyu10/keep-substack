## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`) | Cell gaps inside CommitGrid, icon gap within achievement column |
| sm | 8px (`p-2`, `gap-2`) | Week block internal padding (`p-1` = 4px exception, see below), week-block gaps |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- `py-1` (4px vertical) on each CommitGoalRow — matches existing HeatmapRow convention; do not change
- `p-1` (4px) inside week blocks in CommitGrid — existing convention; do not change
- Achievement column width: `w-8` (32px) for streak=1 (single icon); expand to `w-10` (40px) when streak≥2 (two icons side by side). Header spacer in CommitGoalView must match whichever value is used. Source: CONTEXT.md D-02
- Avatar size: `w-10 h-10` (40px) — touch target standard, existing convention

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / member name | 12px (`text-xs`) | 600 (`font-semibold`) | snug (~1.375, `leading-snug`) |
| Label / fallback text ("未コミット") | 14px (`text-sm`) | 400 (regular) | 1.5 (default) |
| Micro / day names, date labels, week headers | 10px (`text-[10px]`) | 400 (regular) | 1 (`leading-none`) |
| Achievement icons | 14px (`text-sm`) | — (emoji, no weight) | 1 (`leading-none`) |

Achievement icon sizing rationale: `text-sm` (14px) fits within the `h-14` (56px) row height with visible impact. Use `text-xs` (12px) as minimum fallback if layout tightens. Source: CONTEXT.md Claude's Discretion + codebase pattern.

Declared weights: `400` (regular) and `600` (semibold) only. Maximum 2 weights enforced.

## Achievement Icon Display Contract

This section is the core visual contract for Phase 30.

### States

| streak value | Display | Column content | Column width |
|-------------|---------|----------------|--------------|
| 0 | No achievement | Empty (`aria-hidden="true"`) | `w-8` (32px) |
| 1 | Crown only | `👑` | `w-8` (32px) |
| ≥ 2 | Crown + Fire | `👑🔥` (side by side, no separator) | `w-10` (40px) |

Source: CONTEXT.md D-01, D-02

### Layout

- Alignment: `flex items-center justify-center` within the fixed-width column
- Gap between icons when both present: `gap-1` (4px) — tight coupling, not separated
- Font size: `text-sm` (14px) for both icons
- `aria-label`: `"今週達成"` when streak=1; `"連続達成"` when streak≥2
- When streak=0: render `<div className="w-8 shrink-0" aria-hidden="true" />` (unchanged placeholder)

### Header Spacer Sync

`CommitGoalView.tsx` line 35 spacer `<div className="w-8 shrink-0" />` must be updated to `w-10` if and only if the achievement column adopts `w-10`. Keep both in sync atomically.
