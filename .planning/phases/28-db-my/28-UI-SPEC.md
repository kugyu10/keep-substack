## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, `mb-1` label margins |
| sm | 8px | `gap-2`, tight element spacing |

| lg | 24px | `py-6`, modal section padding |

## Component Inventory

### New component: `CommitScheduleModal.tsx`

Location: `src/app/my/CommitScheduleModal.tsx` (Client Component — `'use client'`)

#### States

| State | Trigger | Visual |
|-------|---------|--------|
| Unset (no slots) | No `member_commit_slots` rows passed via props | Render button: `「投稿スケジュールを宣言する」` (full-width, `border rounded px-4 py-2 text-sm font-semibold`, border color `#d8d8d8`, text `#363737`) |
| Set (slots exist) | Slots array is non-empty | Render summary text: `「週N回 — 月曜 8:00、水曜 20:00…」` (14px, regular weight, `#363737`, clickable — `cursor-pointer underline` on hover) |
| Modal open | Button or summary text clicked | Full-screen overlay + centered panel |
| Pending (saving) | "宣言する" clicked, awaiting server action | Button shows `「宣言中...」`, `disabled`, `opacity-50` |
| Error | Server action returns non-null string | `role="alert"` paragraph, `text-sm text-red-600`, above the submit button |
| Validation warning | Duplicate `day_of_week` across slots | Inline warning below the offending slot: `「同じ曜日を複数選択しています」`, `text-xs text-red-600` |

#### Modal overlay structure

```
fixed inset-0 z-50 flex items-center justify-center
  └── bg-black/40  (overlay backdrop, click-outside closes)
      └── bg-[#fafafa] rounded shadow-xl w-full max-w-sm mx-4 p-6
          ├── header row: h2 "投稿スケジュールを宣言" (text-lg font-semibold) + × close button (absolute top-3 right-3, text-gray-400 hover:text-gray-700)
          ├── frequency select row (label + <select>)
          ├── slot rows (dynamic, 1–4 rows)
          │   └── each row: [曜日 <select>] [時刻 <select>] side by side, gap-2
          ├── [optional] validation warning (text-xs text-red-600)
          ├── [optional] server error (text-sm text-red-600, role="alert")
          └── "宣言する" button (full-width, bg-orange-500, text-white)
```

#### Frequency select

- Label: `「週の投稿回数」`, `text-sm font-semibold mb-1`
- `<select>` options: `1`, `2`, `3`, `4`
- Class: `border rounded px-3 py-2 text-sm w-full`
- Default: 1 (or current slot count if editing)

#### Slot rows (day + hour)

Each slot rendered as a flex row (`flex gap-2`):

- **曜日 `<select>`:**
  - Options: 月 (1), 火 (2), 水 (3), 木 (4), 金 (5), 土 (6), 日 (7) — ISO 8601 values
  - Class: `border rounded px-3 py-2 text-sm flex-1`

- **時刻 `<select>`:**
  - Options: `00:00` through `23:00` (integer values 0–23, displayed as `HH:00`)
  - Class: `border rounded px-3 py-2 text-sm w-24`

- Row label: `「スロット N」`, `text-xs text-gray-500 mb-1` (above each row pair)

#### Submit button

- Text: `「宣言する」` — never `「保存する」`
- Class: `w-full bg-orange-500 text-white rounded px-4 py-2 text-sm font-semibold disabled:opacity-50`
- On success: closes modal, `/my` revalidates

#### Close behavior

- × button (top-right): closes modal, discards unsaved changes
- Click outside overlay backdrop: closes modal, discards unsaved changes
- Keyboard: `Escape` key closes modal (add `onKeyDown` handler on overlay)

### /my page integration point

In `src/app/my/page.tsx`, below `<MyProfileForm>`:

```tsx
<div className="mt-8">
  <h2 className="text-sm font-semibold mb-2">投稿スケジュール</h2>
  <CommitScheduleModal memberId={member.id} initialSlots={commitSlots} />

```

- `mt-8` (32px) separates the schedule section from the profile form above
- Section heading: `text-sm font-semibold`, same label style as MyProfileForm fields

## Interaction Contract

### Dynamic slot count

- When frequency `<select>` changes from N to M:
  - If M > N: append (M − N) new slot rows initialised to defaults (day=1 Monday, hour=8)
  - If M < N: remove the last (N − M) slot rows
  - Previously entered values in retained rows are preserved

### Duplicate day validation

- Validation runs on every `<select>` `onChange` event (client-side, no submit required)
- When two or more slot rows share the same `day_of_week` value:
  - Show inline warning `「同じ曜日を複数選択しています」` below the duplicated rows
  - "宣言する" button is NOT disabled by this warning (per D-11: "クライアントサイドで警告" only)

### Accessibility

- Modal container: `role="dialog"` and `aria-modal="true"`
- Modal heading: `aria-labelledby` pointing to the `<h2>` id
- Focus trap: on modal open, move focus to the first interactive element (frequency select)
- On modal close: return focus to the trigger element (the button or summary text that opened it)
- All `<select>` elements have associated `<label>` via `htmlFor` / `id`
- Error paragraph has `role="alert"` (live region, consistent with MyProfileForm pattern)
