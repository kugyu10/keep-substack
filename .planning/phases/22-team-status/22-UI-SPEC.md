## Interaction Contract

### ステータス変更フロー
1. ユーザーが `<select>` でステータスを選択する
2. 「ステータスを保存」ボタンをクリックする
3. Server Action 実行中: ボタンを `disabled` にする（ローディング表示なし、UXシンプル優先）
4. 成功時: ページリロード（`revalidatePath('/admin/teams')`）でテーブルが更新された状態になる
5. エラー時: セル内に赤字テキスト（`text-red-500 text-xs`）でエラーメッセージを表示する

### ステータス表示ルール（トップページ）
フィルタリングロジックの変更は `page.tsx` のみに局所化する:
- タブ一覧: `status === 'public'` のチームのみ表示
- Allビュー: `every(t => t.status !== 'hidden')` でhiddenメンバーを除外

### 確認ダイアログ
- ステータスを `hidden` に変更して保存する操作は `window.confirm()` で確認を求める
- 確認文: 「このチームをhiddenにすると、メンバーがAll表示からも非表示になります。続けますか？」
- `public` / `private` 変更には確認ダイアログを表示しない
