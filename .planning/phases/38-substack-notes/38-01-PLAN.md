# Phase 38 PLAN — ワンボタン共有

## ゴール
対象4ビュー（トップ Commit&Goal / `/daily` / 個人カレンダー / `?team=` 選択ビュー）に再利用可能な `<ShareButton>` を配置し、押すと「定型文＋ハッシュタグ＋公開URL」をクリップボードへコピーし、続けて Substack Notes コンポーザーを新規タブで開く。コピー完了の軽量フィードバックを表示する。既定ではログイン済みユーザーのみ表示する。

## 設計判断（KISS / 既存規約準拠）

1. **公開URLの絶対化**: `buildShareUrl` は相対パスを返す。`src/lib/share.ts` に `buildShareText(view)` を新設し、内部で `buildShareUrl` を呼ぶ。絶対URL化はクライアントで `new URL(relPath, window.location.origin).toString()` を用いる（env のベースURL未定義のため。`window.location.origin` は本番 `https://keep-substack.com` / dev を正しく反映）。→ URL生成ロジックは複製せず Phase 37 ヘルパに委譲。
2. **定型文・ハッシュタグの一元管理 (SHARE-05)**: `src/lib/share.ts` に編集容易な定数 `SHARE_TEMPLATE`, `SHARE_HASHTAG`, `SHARE_NOTES_URL` を置く。`buildShareText({ view, url })` が `${SHARE_TEMPLATE} ${SHARE_HASHTAG}\n${url}` を組み立てる。
3. **ShareButton はクライアントコンポーネント (SHARE-01/02/03/04)**: Clipboard API・`window.open`・フィードバック state のため `'use client'`。`view: ShareView` を prop で受け、内部で相対→絶対URL化＋`buildShareText`。
4. **フィードバック (SHARE-04)**: 重い toast ライブラリは入れない（KISS）。ShareButton 内のローカル state でボタン直下にインライン表示（「コピー完了！貼り付けて投稿してください」）。数秒後に自動で消す。
5. **ログインゲート (SHARE-06)**: 既存パターン（Header → `createSupabaseServerClient().auth.getUser()` → `user` を prop 伝播）を踏襲。各 Server Component ページで `user` を取得し、`<ShareButton view={...} />` を**ログイン時のみレンダリング**。全員表示への切替を1か所にするため `src/lib/share.ts` に `SHARE_REQUIRE_LOGIN = true` 定数を置き、各ページは `(SHARE_REQUIRE_LOGIN ? !!user : true)` で表示判定（フラグ1か所変更で全員表示）。
6. **配置 (SHARE-01)**: 各ビューのヘッダー近く（ViewTabs 直後 / カレンダー見出し付近）に1行 `<ShareButton ... />` で差し込む。配置移動はその1行を動かすだけ。

## タスク

### T1: `src/lib/share.ts`（定数＋共有テキスト組み立て）
- `SHARE_TEMPLATE = 'Substack継続を頑張っています📈'`
- `SHARE_HASHTAG = '#KeepSubstack'`
- `SHARE_NOTES_URL = 'https://substack.com/notes'`
- `SHARE_REQUIRE_LOGIN = true`
- `buildShareText({ view, origin }): { url: string; text: string }` — `buildShareUrl(view)` で相対パス取得、`origin` が与えられれば絶対化、`text = ${SHARE_TEMPLATE} ${SHARE_HASHTAG}\n${url}`。`origin` 省略時は相対URLのまま（テスト容易性）。
- `ShareView` 型は `shareUrl.ts` の型を再利用（export して import）。

### T2: `src/components/ShareButton.tsx`（クライアント）
- `'use client'`
- props: `view: ShareView`（`className?` 任意）
- onClick: `buildShareText({ view, origin: window.location.origin })` → `navigator.clipboard.writeText(text)` → 成功で `window.open(SHARE_NOTES_URL, '_blank', 'noopener,noreferrer')` → インラインフィードバック表示。clipboard 失敗時はエラー文言。
- 既存ボタンのデザイン規約（`text-sm border rounded px-3 py-1 hover:bg-gray-50`）に合わせる。ラベル「共有」＋アイコン任意。

### T3: 4ビューへの配置（ログインゲート込み）
- `src/app/(main)/page.tsx`: `createSupabaseServerClient().auth.getUser()` 追加、`SHARE_REQUIRE_LOGIN ? !!user : true` で `<ShareButton view={{ type: 'goal', team }} />` を ViewTabs 付近に配置。
- `src/app/(main)/daily/page.tsx`: 同様に `view={{ type: 'daily', team }}`。
- `src/app/(main)/member/[publicationId]/page.tsx`: `view={{ type: 'member', publicationId, ym: ym ?? formatYmParam(year, month) }}`。
- team 選択ビューは同一ページの `team` 変数を view に渡すことで自動追従（別ページ不要）。

### T4: テスト `src/lib/__tests__/share.test.ts`
- `buildShareText` が template+hashtag+URL を正しく組み立てる（origin あり/なし）。
- 4ビュー（goal / goal+team / daily+team / member+ym）で正しい URL が埋まる。
- `SHARE_REQUIRE_LOGIN` が true（既定ログインゲート）であること。
