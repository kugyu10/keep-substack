## What Was Built

### CommitGridCell.tsx (new)

A `'use client'` component accepting `href?`, `title?`, and `children`. Renders `<a>` when `href` is present, `<div>` otherwise. Both carry `className="group relative h-full block"`. When `title` is truthy, an absolutely-positioned `<span>` tooltip renders above the cell using `opacity-0 pointer-events-none group-hover:opacity-100 transition-opacity duration-150`. No `useState`, no `useEffect`, no JS event handlers — CSS only.

### CommitGrid.tsx (updated)

Added `import CommitGridCell from './CommitGridCell'`. Three achieved-cell rendering patterns now use `CommitGridCell`:

- Pattern A (thumbnail + link) — `<CommitGridCell href={article.link} title={article.title}>`
- Pattern B (thumbnail, no link) — `<CommitGridCell title={article.title}>`
- Pattern C (no thumbnail, imageUrl/✓ fallback) — `<CommitGridCell href={article.link ?? undefined} title={article.title}>`

Unachieved (dashed-border) cells are unchanged. The `// Server Component — do NOT add 'use client'` comment and Server Component status are preserved.
