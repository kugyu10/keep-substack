## Task Boundary

CommitGoalView / CommitGoalRow で、コミットスロット未設定メンバーの表示を2状態に分離する。
現状は `slots.length === 0` のメンバーが Group B / Group C どちらも同じ「未コミット」表示になっている。
</domain>

<decisions>
## Implementation Decisions

### 用語の対応（確認済み）
- 未コミットメント = Group B = `hasUser=true` かつ コミットスロットなし
- 未登録 = Group C = `hasUser=false`（auth ユーザー未連携）

### 表示ラベル
- Group C（未登録） → 「未登録」
- Group B（未コミットメント） → 「未コミットメント」
- （現状はどちらも「未コミット」表示）

### 未登録（Group C）行の見せ方
- 淡色グレーで控えめに表示（登録を促す存在として目立たせない）

### ソート
- 現状維持。`getGroup` が既に A=0/B=1/C=2 を返し、ソートは group 昇順のため未登録(C)は最下段。ロジック変更なし。

### Claude's Discretion
- 淡色の具体的な強度（opacity / text-gray の階調）は実装側で調整
- ラベル文言の最終的な字面（「未コミットメント」の長さがレイアウトに影響する場合の折り返し可否）
</decisions>
