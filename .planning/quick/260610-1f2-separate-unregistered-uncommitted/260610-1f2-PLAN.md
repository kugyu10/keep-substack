# Quick Task 260610-1f2: 「未登録」と「未コミットメント」の表示分離

## Objective

CommitGoalRow の「コミットスロット未設定」表示を、メンバーの `hasUser` で2状態に分離する。
- Group B（`hasUser=true`・スロットなし）= 未コミットメント → ラベル「未コミットメント」
- Group C（`hasUser=false`）= 未登録 → ラベル「未登録」＋行を淡色グレーで控えめに

ソートロジック（`getGroup` / `sortMembersForCommitView`）は変更しない（既に A→B→C で未登録が最下段）。

## Tasks

### Task 1: CommitGoalRow の no-commit 分岐を hasUser で分離
- **files:** `src/components/CommitGoalRow.tsx`
- **action:**
  - `member.hasUser === false` を「未登録」判定とする変数を導入
  - 未登録時はルート行に控えめな淡色（opacity）を付与
  - Column 2 の `slots.length === 0` 分岐で、未登録 → 「未登録」（さらに淡いグレー）、それ以外 → 「未コミットメント」を表示
- **verify:** `npm test -- CommitGoalRow` がグリーン、型チェック通過
- **done:** 未登録/未コミットメントが別ラベルで描画され、未登録行が淡色になる

### Task 2: テスト追加
- **files:** `src/components/__tests__/CommitGoalRow.test.tsx`
- **action:** hasUser=false+slotsなし→「未登録」、hasUser=true+slotsなし→「未コミットメント」を検証するケースを追加
- **verify:** `npm test -- CommitGoalRow` グリーン
- **done:** 両状態の文言が回帰テストで担保される

## Out of scope
- ソート順の変更（現状維持）
- getGroup / commitUtils の変更
